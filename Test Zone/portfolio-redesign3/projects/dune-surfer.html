About this project

An arcade game about speed and flow. You surf down an endless desert, using the slopes to build speed and the crests to launch into the air, and every trick you land adds to your score.

Key features

  • Endless dunes: Terrain is generated in chunks from layered noise as you move, so every run is different.
  • Surf physics: Speed comes from the slope under you. Time a jump off a crest to get more air.
  • Tricks and combos: Spins and flips score points, and chaining them builds a multiplier.
  • Global leaderboard: Scores are submitted online so players can compete with each other.

Challenges and what I learned

Generating terrain at speed without hitches. New chunks have to be built and joined seamlessly to the old ones while the player is moving fast, so the work is spread across several frames instead of done all at once.
