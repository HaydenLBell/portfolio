About this project

Coursework for Hardware-Software Interfacing at Heriot-Watt. The Pi picks a secret sequence of colours, and the player has a limited number of turns to guess it, with feedback after each guess on how close they were.

Key features

  • Button input: Each colour is entered by pressing the button a set number of times, with a timeout to end each input.
  • LED feedback: A green and a red LED blink to show how many colours are exactly right, and how many are right but in the wrong place.
  • LCD display: A 16x2 LCD shows the guess and the result for each round.
  • Direct hardware access: The GPIO pins are controlled through memory-mapped registers, with the low-level parts written in ARM assembly instead of using a library.

Challenges and what I learned

Buttons are noisy: one physical press can register as several. Debouncing the input and timing the presses reliably, while keeping the LEDs and LCD responsive, took more care than the game logic itself.
