About this project

On a Formula Student car, the vehicle control unit (VCU) sits at the centre of the car's electronics. The other controllers talk to it over the CAN bus, and it decides how the car responds.

I designed and wrote the VCU software in embedded C over two seasons with HW Racing, working with the electrical and powertrain sub-teams.

Key features

  • CAN message handling: Decodes frames from the car's other controllers and sends commands and status back out, checking IDs, lengths and timing on every message.
  • Fault detection: Watches sensor readings and message timeouts, and puts the car into a safe state when something stops making sense.
  • Watchdogs: Reset the system if a task stops responding, so a hang never leaves the car in an unknown state.
  • Defensive C: Bounds checking on buffers and inputs, and static analysis before any code ran on the car.

Challenges and what I learned

The hardest part was deciding what "safe" means for each fault. A lost sensor reading might need the car to stop, while a late status message might only need logging. Get it wrong one way and the car stops for nothing; get it wrong the other way and a real fault goes unnoticed.

It taught me to design how the system fails first, and write the normal path second.
